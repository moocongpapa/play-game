# 개발 환경·배포·문제 해결

기준일: 2026-10-10 · [목차](README.md)

## 로컬 실행

1. Node.js 22 이상, npm, Git을 준비합니다. 영상·음원 편집 도구만 FFmpeg를 추가로 사용합니다.
2. 저장소 루트에서 `npm install`을 실행합니다. 현재 저장소에는 lockfile이 없으므로 `npm ci`를 사용할 수 없고 설치 버전은 `package.json` 범위에 따라 달라질 수 있습니다.
3. `.env.example`을 `.env.local`로 복사합니다. 키가 없으면 값을 비워 둡니다.
4. `npm run dev`를 실행하고 터미널의 접속 주소를 엽니다. 기본 주소는 `http://localhost:3000`입니다.

`dev`는 모든 로컬 네트워크 인터페이스에 바인딩합니다. 휴대폰에서 확인하려면 같은 네트워크의 컴퓨터 IP와 Vite의 실제 포트를 사용합니다. HTTP IP 주소에서는 보안 컨텍스트가 필요한 PWA·Web Crypto 기능이 localhost/HTTPS와 다를 수 있습니다.

## 환경 변수

현재 앱은 데이터베이스·Firebase·Google Drive·별도 `VITE_API_URL`을 사용하지 않습니다. 브라우저의 음성 요청은 같은 출처의 `/api/speech`로 갑니다.

| 변수 | 사용 위치·필수 여부 |
|---|---|
| `ELEVENLABS_API_KEY` | 서버의 새 음성·효과음 생성과 유지보수 음원 제작. 게임 기본 실행에는 선택 사항 |
| `GEMINI_API_KEY` | 수동 세로 영상 생성. ElevenLabs 키가 없는 배포의 기존 Gemini TTS 호환 경로에도 사용 |
| `UPSTASH_REDIS_REST_URL` | 배포 음성 API의 HTTPS 공유 사용량 저장소. 토큰과 함께 설정 |
| `UPSTASH_REDIS_REST_TOKEN` | 위 저장소 서버 전용 토큰 |
| `FFMPEG_PATH` | 세로 영상·더빙 도구의 FFmpeg 실행 파일. 기본 `ffmpeg` |
| `CARE_FFMPEG` | 생활습관 음성 검증·편집 도구의 FFmpeg 실행 파일. 기본 `ffmpeg` |
| `DISABLE_HMR` | `true`이면 개발 HMR·파일 감시 중지. 일반 개발에서는 생략 |

API 키와 Redis 토큰에 `VITE_` 접두사를 붙이지 않습니다. `.env.local`은 Git에서 제외되며 브라우저 번들에 포함하지 않습니다. FFmpeg 경로는 환경 변수 또는 명령 앞의 변수로 지정합니다. 환경 설정을 바꾼 뒤 개발 서버를 재시작합니다.

## 개발 서버와 배포 서버

| 환경 | 음성 API |
|---|---|
| `npm run dev` | `vite.config.ts`의 미들웨어가 같은 음성 처리기를 실행. 요청 수는 프로세스 메모리에서 제한 |
| `npm run preview` | 정적 `dist/` 확인만 제공. `/api/speech` 없음; 저장 음성과 기기 음성으로 대체 |
| Vercel | `api/speech.ts`의 Node 함수와 정적 Vite 앱. 배포 환경 변수는 플랫폼에서 설정 |
| 다른 정적 호스팅 | 게임·공개 자산만 제공. 새로운 AI 음성을 쓰려면 Node 음성 경로를 별도로 연결해야 함 |

`vercel.json`은 `/api/*`를 제외한 앱 경로를 `index.html`로 연결합니다. 음성 SDK에 Node 런타임이 필요하므로 Edge 전용 함수로 바꾸지 않습니다. Vercel이 설정하는 클라이언트 IP 헤더는 Vercel 환경에서만 사용합니다.

공유 Redis를 설정하지 않은 배포는 **추가 과금이 꺼진 Free·Starter ElevenLabs 계정**으로 검증되는 경로만 허용합니다. 배포의 Gemini-only TTS는 Redis가 있어야 동작합니다. 공유 사용량 저장소를 설정했는데 연결이 실패하면 생성 요청을 중단합니다. 한도·요청 계약은 [오디오 문서](audio.md)에 있습니다.

## PWA와 오프라인

- `index.html`과 `public/manifest.webmanifest`에 젤리 아이콘·설치 메타데이터가 있습니다. 설치 안내와 원본은 [아이콘 문서](../public/icons/README.md)를 참고합니다.
- `src/main.tsx`는 개발 환경을 제외하고 창 로드 후 `public/sw.js`를 등록합니다. localhost 또는 HTTPS 환경이 필요합니다.
- 서비스 워커는 앱 진입 HTML·아이콘을 미리 저장하며 방문한 스크립트·스타일·이미지·폰트·포스터 등을 저장합니다. 경로 이동은 네트워크 우선, 정적 자산은 저장본을 보여 주고 갱신합니다.
- API, 외부 출처, MP4 영상과 모든 음원 전체를 미리 저장하지 않습니다. 음성은 별도 IndexedDB 캐시를 사용합니다. 아직 열지 않은 지연 로딩 게임은 오프라인에서 준비되지 않았을 수 있습니다.
- 캐시 버전은 `public/sw.js`의 `CACHE_NAME` 값으로 관리합니다. 설치 검증은 실제 기기에서 따로 진행합니다.

## 자주 생기는 문제

| 증상 | 확인 순서 |
|---|---|
| 음악·효과음만 나오고 안내가 없음 | 전체 음소거, 저장된 TTS 설정, 부모 화면의 엔진 상태, 음성 파일 응답, `/api/speech` 응답, 기기의 언어 음성 지원 |
| 첫 접속이나 영상 종료 후 소리가 없음 | 화면을 한 번 누르고 놓아 AudioContext를 활성화. 앱의 전체 소리·음성 설정과 기기 미디어 볼륨 확인. iPadOS/iOS 17 이상 지원 브라우저는 playback 오디오 세션을 사용하고, 구형 버전은 시스템 무음도 해제. 영상 종료 복구는 다음 터치에도 연결되어 있음 |
| 배포에서 새 음성이 없음 | 서버 키, Node 함수 배포 여부, 포함 크레딧·초과 과금 설정, 공유 Redis 상태 확인. 정적 preview에는 API가 없음 |
| HTTP 429 | 공유 요청 한도 또는 공급자 포함 크레딧 제한. `Retry-After`와 부모 상태 확인. 저장된 음성·기기 음성으로 계속 진행 |
| HTTP 503/502 | 미설정·검증 불가·저장소 또는 공급자 오류. 다른 유료 공급자로 자동 전환하지 않음 |
| 그림이 다른 기기에 없음 | 전시회는 현재 브라우저 IndexedDB에 저장. 원래 기기에서 PNG로 내보내기 |
| 메뉴에 단어 퍼즐이 없음 | 꽃잎반(48개월 이상)부터 표시. 현재 생년월일과 월령 확인 |
| 영상이 가로로 나옴 | 세로 완성 여부를 manifest에서 확인. 미완성 캐릭터는 기존 가로 영상 사용 |
| 부모의 진행 초기화 후 그림이 남음 | 초기화는 앱 상태만 지움. 별도 프로필과 그림 IndexedDB·음성 캐시는 유지 |

무료 상태 확인은 앱 부모 화면 또는 같은 출처의 `GET /api/speech`를 사용합니다. **POST 음성 요청·제작 스크립트는 생성 크레딧을 쓸 수 있으므로** 단순 연결 확인을 위해 새 콘텐츠를 만들지 않습니다.
