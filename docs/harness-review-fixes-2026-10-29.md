## 리뷰 항목과 조치

| 항목 | 반영한 수정 | 검증 |
|---|---|---|
| 설정 초기화의 작품 삭제 | 앱 상태·프로필 키만 초기화. 전시회·초안·음성 IndexedDB 보존, 보호자 확인문 보완 | 실제 저장 모듈 + fake-indexeddb에서 그림·음성 유지 |
| 요술 마이크 연타·종료 누수 | 한 권한 요청/녹음 세션, 닫기·숨김·부모 정지·언마운트 취소. 늦은 스트림·디코딩 폐기 | 가짜 미디어로 연타·재열기·닫기·녹음 종료·지연 decode 검증 |
| 물약 재료 잘림 | 세로 3×2, 넓은 화면 6열, 가로 별도 배치. 모든 버튼 최소 64px | 320×568에서 여섯 버튼 84×64px, 844×390에서 66×64px 확인 |
| 트램펄린 매초 초기화 | 물리 초기화와 최신 완료/음성 콜백 분리, App 완료 함수 안정화 | 부모 재렌더 뒤 별 DOM 유지·정지 시 transform 고정 |
| 음소거 중 단계 잠김 | 안내 설정과 언마운트 정리 분리. 예약 콜백은 최신 소리 설정 사용 | 물약 brewing 중 소리 토글 후 완성·자동 다음 판 |
| 최종 판 뒤 멈춤 | 팝콘·공룡 알·과일 캐치·물약·숲속·슬라임·목욕 자동 이어가기 | 물약 3판 뒤 네 번째 레시피, 팝콘 3맛 뒤 첫맛·보상 1회 |
| 과일의 순간 이동 | React는 항목 생성/삭제, RAF는 DOM transform 갱신. 표시·충돌 좌표 통일 | 프레임 시계·320/820/1440 충돌 계산, PC 실제 이동 확인 |
| 보호자 확인 뒤의 진행 | 공통 활동 상태·정지 가능한 지연 작업, 물리의 활성 시간 시계 | 보호자/숨김 중 정지·남은 지연 보존·복귀·취소 |
| 색칠/녹음 볼륨 우회 | 공통 AudioContext·효과음 버스 사용 | 0%·전체 음소거·숨김·덕킹·로봇 LFO 종료 회귀 |
| 짧은 화면 방문 시간 누락 | 이전 화면 clock을 정리하기 전에 마지막 분수 초 정산 | 800ms 방문 75회 = 60초 및 제한 도달 |
| 시크릿 보호 누락 | 인자·인용·셸 중첩·Git pathspec 검사. 외부 pathspec 목록과 강제 전체 추가 차단 | 명령 문자열만 전달하는 CLI 모의 테스트, 실제 Git 명령 실행 없음 |

훅 명령은 Git 루트를 찾아 파일을 실행하고 종료 훅은 `import.meta.url`로 저장소를 계산한다. 저장소 루트와 `.agents/`에서 두 명령을 실행해 확인했다. 자동 훅 등록은 사용하는 호스트의 설정에 따르며 이 파일만으로 등록을 보장하지 않는다.

## 자동 검증

- `npm run harness:check`: 40개 놀이 등록/레이아웃/정리/유료 스크립트 격리 및 새 상태 전환·초기화 검사 통과.
- `npm run lint`: 통과.
- `npm test`: 143개 통과. API 공급자·녹음·저장소는 가짜 응답으로 확인하며 유료 생성 없음.
- `npm run build`: 통과. 지연 로드 Pixi 청크 522KB의 기존 크기 경고는 남음.
- `/tests/review-regressions.html`: 실제 React·캔버스 회귀 10개 통과. 도화지/지우개·부모 정지·남은 지연·트램펄린 재렌더·물약 소리 토글/자동 반복·팝콘 반복·풍선 연속 기록 확인.

브라우저 회귀는 음성 엔진을 꺼서 실행하며, UI 확인용 개발 서버와 정적 미리보기에는 `/api/speech` 공급자를 연결하지 않았다. 검증 전용 개발 서버는 사용 중인 개발 서버와 캐시를 분리했다.

## 화면 확인과 제한

- 정적 빌드의 320×568 모바일: 필수 첫 재료 탭, 젓기, 음소거 중 완성, 다음 레시피 자동 시작.
- 820×1180 태블릿: 여섯 재료 한 줄 표시. 844×390 가로: 오른쪽 2열·3줄, 모든 버튼과 놀이 영역 표시.
- 1440×900 PC: 과일 캐치, 보호자 확인창 중 좌표 고정과 이동 버튼 비활성화, 닫은 뒤 재개.
- 이미지·음성·영상 원본은 변경하거나 축소하지 않았다. 새 API 생성 비용 없음.
- 실제 iPad/iPhone의 마이크 권한·청감·멀티터치와 OS 제스처는 실기기 확인이 필요하다. 화면 크기 확인을 실기기 검증으로 간주하지 않는다.

정적 하네스는 모든 동작을 증명하지 않는다. 음소거·연타·보호자 정지·마지막 라운드 같은 상태 변화는 자동 테스트와 브라우저 회귀를 함께 실행한다.
