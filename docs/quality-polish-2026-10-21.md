# 그림책 품질 개선 · 2026-10-21

[문서 목차](README.md)

## 반영한 내용

1. 실제 완료는 `recordPlaySuccess`, 장식은 `emitJuice`로 분리했다. 정답·컨페티·자동 다음 장면이 같은 성공을 여러 번 올리지 않는다. 중복 전역 축하와 화면 위 영어 피버 배지를 제거했다.
2. 생활 놀이 효과를 얼굴 바깥으로 옮겼다. 잠자리·감정 거울·감각 캔버스는 공통 파티클·흔들림·콤보를 사용하지 않는다. 컨페티 중복 호출은 600ms 안에서 한 번으로 제한한다.
3. 세로 선택 화면은 2×2 배치에서 카드와 내부 그림을 함께 키운다. 태블릿에서 그림이 약 94px로 제한되던 안쪽 래퍼를 수정해 190px까지 보여 준다. 낮은 가로 화면은 네 선택지를 한 줄로 배치한다.
4. 홈 게임 카드 이름표를 제거했다. 접근성 이름과 음성은 유지한다. 블록 안내·정가운데 배지는 그림으로 바꿨다.
5. 숫자 놀이터를 아기반부터 노출한다. 범위는 0~10 / 0~20 / 0~100을 유지한다. 전체 34종, 새싹반 32종이며 부모가 끈 게임은 계속 제외한다.
6. 블록 놀이를 그림책 풍경·파스텔 나무 장난감·실제 투하/착지·손 그림 시범으로 다시 구성했다. 화면 크기에 따라 크레인 범위·블록 높이·탑·친구를 계산한다. 자동 다음 판은 공통 진행기를 사용한다.
7. 먹여주기는 시선 → 입 벌리기 → 캐릭터별 씹기 리듬 → 짧은 만족 미소로 이어진다. 음식 이름과 반응 문구는 보조 정보로 숨겼다.
8. 저장 음성에 친구별로 작은 공명 차이를 적용한다. 재생 속도·피치를 추가 변경하거나 새 음원을 생성하지 않는다. 음성 버스와 효과음 버스를 분리해 말하는 동안 효과음은 28%로 낮춘다.
9. 바람 아이콘은 관련 네 놀이에만 64×64px로 표시한다. 기본은 버튼 반응이며 마이크 허용은 보호자 설정에서 한다. 게임에서는 이미 허용된 권한을 확인할 수 있을 때만 연결한다. 미해결 스트림·반복 요청·화면 이탈을 정리하고, 다른 놀이로 넘어가거나 부모 설정을 열면 마이크를 끈다.
10. 환영은 실제 홈 모듈 준비 후 다음 프레임에 끝난다. 고정 5.2초를 제거하고 효과 렌더러·큰 음성 목록을 지연 로드했다. 공통 preload helper를 별도로 분리해 렌더러가 첫 HTML에 딸려오지 않게 했다.
11. PullToy의 키보드 합성 이벤트를 실제 포인터 캡처와 구분했다. Enter 한 번으로 한 동작만 수행하고 길게 누른 키 반복을 무시한다.

## 확인한 범위

- `npm run lint`, `npm test` 127개, `npm run build` 통과.
- 키 없는 정적 미리보기에서 확인했다. 유료 생성 요청·수동 생성 스크립트 실행 없음.
- 390×844 모바일: 그림 전용 홈 → 블록 여섯 개 투하 → 자동 다음 판, 바람 탭, 이름 찾기 정답 한 번 → 성공 한 번, 먹여주기 입 드롭, 숫자 두 읽기 버튼.
- 320×568: 이름 찾기 네 보기와 하단 버튼 잘림 없이 표시.
- 820×1180 태블릿: 이름 찾기 네 그림을 190px로 확대하고 2×2 배치 확인.
- 1440×900 PC, 844×390 가로: 블록 장면 표시와 가로 여섯 개 투하 확인.
- 844×390 가로: 이름 찾기 네 선택지를 한 줄에 배치하고 하단 버튼까지 잘림 없이 표시.
- 잠자리: Enter로 불 끄기·이불 덮기, 인형을 품에 놓기 → 잠든 얼굴. 피버·폭죽 없음. 이전 `setPointerCapture` 오류 재현되지 않음.
- 보호자 게이트가 열린 동안 숫자 버튼 비활성화, 닫고 홈으로 복귀 확인. 실제 마이크 권한 허용과 하드웨어 녹음은 실행하지 않았다. 스트림 수명은 가짜 미디어를 사용한 회귀 테스트로 검증했다.
- 기존 오디오 파일 무결성·같은 음성 연타·언어·음소거·영상 종료 후 오디오 복구 테스트 통과. 실제 iPad 청감·진동·멀티터치는 별도 기기 검증이 필요하다.
- `public/` 미디어 원본 변경 없음. 새 녹음·이미지·영상 생성 비용 없음.

## 성능과 제한

첫 앱 파일은 약 511.6KB에서 201KB로 줄었다(압축 전, 빌드에 따라 해시/소수점 변동). 246.6KB 저장 음성 목록과 522.2KB Pixi 렌더러는 각각 첫 음성 및 해당 놀이 진입 시 요청한다. 렌더러의 500KB 청크 경고는 남지만 초기 HTML의 modulepreload 목록에서는 제외됐다.

브라우저가 마이크 권한 조회를 지원하지 않거나 권한이 거부되면 버튼으로 동일한 바람 놀이를 한다. 기존 목소리 기본 음색은 유지하며 이번에는 재생 공명·표정 리듬을 다듬었다. 새로운 성우나 음원으로 교체한 작업은 아니다.
