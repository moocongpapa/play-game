# 통통 숫자 놀이터

- 홈의 숫자 그림 카드를 누르면 시작한다. 모든 연령과 선택한 친구의 음성을 지원한다.
- 두 버튼은 **하나의 숫자**를 이어서 올린다. 첫 터치는 0, 이후 1~100, 다음 터치는 다시 0이다.
- 토끼: 하나·둘·셋·넷, 열·스물·서른…아흔아홉. 곰: 일·이·삼·사, 십·이십·삼십…구십구. 0은 영, 100은 백이다.
- 영어 음성 설정에서는 두 버튼 모두 영어 숫자를 읽는다. 한글 글자 놀이의 ‘이’와 숫자 ‘이’의 영어 번역이 섞이지 않도록 숫자에만 영어 읽기를 전달한다.
- 숫자는 6가지 모션과 색 변화, 별·하트 입자, 무지개 배경, 수량 구슬로 반응한다. 10마다 별을 받고 100 이후에도 계속 놀 수 있다.
- 연속 터치는 시각적으로 즉시 반영한다. 음성은 첫 숫자를 마친 뒤 마지막 요청만 읽고, 같은 숫자 재듣기는 중복 대기열을 만들지 않는다. 음소거·보호자 화면·홈 복귀 시 대기 음성을 취소한다.
- 기존 ElevenLabs 우선 음성 엔진과 저장 캐시를 사용한다. 새 숫자 음성은 처음 사용할 때 준비되며, 저장된 음성은 재사용한다.

## 검증

- 모바일 390×844에서 0~100 진행, 100→0 순환, 두 읽기 방식 변경 확인.
- 태블릿 768×1024, PC 1440×900, 작은 휴대폰 320×568, 가로 휴대폰 844×390에서 조작과 버튼 배치 확인. 화면 넘침 없음.
- 실제 로컬 음성 API에서 ‘하나’, ‘일’ 모두 HTTP 200 / `elevenlabs` / `audio/mpeg` 응답 확인.
- 숫자 변환·빠른 입력·음성 취소·영어 숫자 문맥 테스트를 포함해 115개 테스트 통과. lint·build 통과.
- 브라우저 화면 크기 검증이며 실제 기기의 스피커 음질과 진동은 별도 확인 대상이다.
