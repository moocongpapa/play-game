# 유하 연결 놀이 개선

작업: 2026-11-03~04. 신규 게임 ID 추가 없이 기존 44종의 조작과 연결을 개선했습니다.

## 반영한 여섯 가지

1. **큰 도구와 빠른 반복**: 스크래치·케이크·살롱·물풍선 색칠의 설명 배너를 작은 그림 안내로 바꾸고 도구를 64px 이상으로 키웠습니다. 케이크는 크림/토핑 두 도구를 전환하며, 색을 누르면 방금 고른 색이 즉시 적용됩니다. 세 장면 사이 대기는 700ms이고 마지막 뒤에도 자동 반복합니다. 부모 인증·백그라운드에서는 입력/지연을 멈춥니다.
2. **세 이야기**: 과일 소풍(수확→세기→먹기), 생일(케이크→먹기→실로폰), 잠자리(먹기→양치→잠자리)를 그림으로 고릅니다. 마지막 장면 다음에는 다음 이야기로 이어집니다. 선택한 친구와 기존 완료 기록을 유지하며 보호자가 끈 게임을 포함한 이야기는 표시하지 않습니다.
3. **이어지는 결과물**: 실제로 딴 과일을 최대 여섯 개 보관해 세기와 먹기에 사용합니다. 먹은 과일 ID만 한 번 소비합니다. 최근 케이크는 먹여주기 접시에 등장하고 색칠한 자동차/로켓은 놀이터에서 선택 친구와 탈 수 있습니다. 그림 전시회 데이터는 그대로 유지합니다.
4. **행동에 맞춘 친구 반응**: 실제 색·음식·작품을 짧은 음성으로 언급합니다. 여덟 친구의 반동 모양과 리듬이 다르며 수확·먹기·잠자리에 반영했습니다. 마지막 사용 색은 다음 잠자리 이불에 반영하고 최근 케이크/과일을 꿈 그림으로 보여 줍니다.
5. **단계별 도움**: 공통 드래그는 두 번/네 번 놓치거나 4초/8초 멈추면 도움을 키웁니다. 자석 오차를 최대 130px까지 늘리고 목표와 탭 대안을 보여 줍니다. 이름/소리/모양/그림자 보기의 위치를 유지하면서 일부 오답 그림만 부드럽게 줄여 보입니다. 아기반/새싹반의 모양/그림자 게임은 가장 높은 도움 단계에서 정답 그림 한 번 누르기로 놓을 수 있습니다. 틀린 그림을 정답으로 처리하지 않습니다.
6. **개인 홈 바로가기**: 최근·자주 고른 놀이를 그림 세 개로 보여 줍니다. 전체 목록은 페이징 없이 기존 순서로 모두 유지하고 글자 캡션/배지는 제거했습니다. 게임 종료 시 기존 홈 스크롤 복귀를 유지합니다.

## 데이터와 오디오

- `PlayMemoryProvider` / `playMemory.ts`: `ITSME_PLAY_MEMORY_V1`에 작은 JSON만 저장합니다. 알려진 게임 ID·색·종류를 검증하고 개수를 제한합니다. 저장이 막힌 브라우저에서도 현재 세션의 놀이는 가능합니다.
- 이 기억은 현재 브라우저에만 있습니다. 다른 기기로 동기화하지 않습니다. 최신 케이크/탈것만 기억하며 전시회 전체 작품과는 별도입니다. 설정 초기화는 작품처럼 이 작은 결과물을 보존합니다.
- `connectedPlaySpeech.ts`에 한국어/영어 대응 문구를 등록했습니다. 기존 ElevenLabs 우선·저장 음성 재사용·기기 음성 대체 흐름과 음소거를 따릅니다.
- 유료 음성/영상 생성 스크립트는 실행하지 않았습니다. 브라우저 회귀는 마스터 오디오를 끈 상태이며 실제 공급자 호출이 없습니다.

## 검증

- `npm run harness:check`, `npm run lint`, `npm test` **153개**, `npm run build` 통과.
- `/tests/connected-play.html` **9개 통과**: 전체 홈/개인 바로가기, 케이크 색 상태·도구 크기·반복, 살롱/물풍선 반복, 스크래치 반복, 부모 정지·복귀, 과일 소비, 생일 이야기 전체 자동 진행, 반복 오답 후 탭 도움, 탈것 탑승 시 친구 중복 방지.
- 기존 `/tests/review-regressions.html` **10개 통과**: 그림 PNG/지우개, 시간/일시정지, 효과/정리, 트램펄린·물약·팝콘·풍선 반복 회귀.
- 실제 빌드 브라우저에서 320×568 케이크, 390×844 살롱, 768×1024 물풍선 색칠, 1440×900 스크래치, 844×390 가로 케이크를 열고 스크린샷·도구 경계를 확인했습니다. 도구는 64px 이상이고 가로 넘침이 없습니다.
- 시각 검토에서 손동작 안내 SVG가 그림 크기 규칙을 받아 커지는 문제를 찾아 40px로 제한했습니다. 이야기 진행 그림을 뺀 남은 높이를 게임에 적용해 아래 도구가 화면 밖으로 밀리지 않게 했습니다.

## 남은 범위

- 화면 크기 검증은 데스크톱 Chromium 브라우저입니다. 실물 iPad 홈 설치 모드와 실제 손가락 조작·스피커 청취를 새로 검증한 것은 아닙니다.
- 기존 선택 로드 Pixi 청크 약 522kB의 Vite 크기 경고는 남아 있습니다. 빌드는 성공하며 초기 홈 진입에는 지연 로드됩니다.
- 이번 QA는 변경한 흐름과 공통 회귀를 대상으로 했으며 44종을 모든 크기에서 끝까지 새로 플레이했다고 주장하지 않습니다.
