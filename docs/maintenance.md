# 검증·파일 정리·유지보수

기준일: 2026-10-09 · [목차](README.md)

## 이번 정리의 확인 방법

전체 `src/`, `api/`, `scripts/`, `tests/`와 Vite 설정의 TypeScript/TSX **208개 파일**을 파싱해 정적 import·export·동적 import 연결을 확인했습니다. 앱·API·수동 제작 도구·자동 테스트·수동 테스트를 모두 진입점으로 삼고, 연결되지 않은 파일을 저장소 전체 참조 검색으로 다시 확인했습니다. 코드에 직접 연결되지 않은 제작 자산은 원본·manifest·생성 계획과 함께 대조했습니다.

문서는 현재 동작을 설명하는 운영 문서와 당시 입력·결과를 보존하는 제작/검증 기록으로 구분했습니다. 과거 기록의 테스트 수를 최신 결과처럼 바꾸지 않았습니다.

## 제거한 파일과 설정

| 제거 대상 | 확인한 이유·현재 대체 |
|---|---|
| `src/components/BuddyVideo.tsx` | 어떤 진입점에서도 사용하지 않는 배경 영상 컴포넌트. 현재 영상은 CharacterCharmVideoModal |
| `src/components/CharacterGreeting.tsx` | 현재 인사 화면에서 사용하지 않음. CharacterTalkScreen이 인사 동작을 직접 표시. 공용 CharacterGreeting.css는 여전히 사용하므로 보존 |
| `src/screens/StickerRoomScreen.tsx` | 앱의 같은 내부 화면 이름은 곤충 놀이터를 렌더. 현재 색칠 스티커는 별도 sketch 시스템 |
| `src/services/googleDrive.ts` | 호출·import하는 소스와 화면이 없음. 현재 영상은 공개 로컬 MP4, 그림은 IndexedDB |
| `firebase-applet-config.json` | 위 미사용 Drive 모듈만 참조하던 Firebase 설정 |
| `src/theme/colors.ts` | 어떤 소스·테스트에서도 import하지 않는 예전 7명 색상표. 현재 characterArt·화면 스타일로 관리 |
| `scripts/generate-character-videos.ts` | 이전 720p 가로 제작·병렬 생성 도구. 현재 세로·순차·비용 정책과 작업 기록 복구는 generate-portrait-videos.ts 사용 |
| `scripts/build-30s-character-videos.ts` | 같은 짧은 영상을 반복·확대해 30초로 만드는 이전 도구. 현재는 서로 다른 네 장면을 편집 |

직접 사용하는 import가 없는 Firebase, Express, dotenv, Howler, 별도 framer-motion, autoprefixer, esbuild 및 관련 Express/Howler 타입 의존성을 제거했습니다. Motion이 내부적으로 사용하는 framer-motion, Vite가 내부적으로 사용하는 esbuild 등 **전이 의존성**은 설치 도구가 관리합니다. 직접 의존성과 전이 의존성의 제거는 다릅니다.

중복 선언된 Vite와 실행에 필요 없는 환경 예제(`DATABASE_URL`, `VITE_API_URL`, Firebase 변수)를 정리했습니다. Canvas-confetti 타입은 개발 의존성으로 옮겼습니다. `package.json`의 이름을 서비스 이름에 맞추고 `clean`은 실제 산출물 `dist/`만 삭제하도록 변경했습니다.

## 보존하는 파일

- `public/`의 현재 이미지·음원·영상·포스터·설치 아이콘·도안. 작은 크기로 다시 압축하거나 해상도를 낮추지 않았습니다.
- `production/character-videos/`의 계획, 시작 프레임, 게임 외형 참조, 더빙·완료 manifest. 앱에서 직접 import하지 않아도 제작·검수·재개에 사용합니다.
- `backups/character-videos/2026-10-09-landscape/`의 원본 8개, 체크섬과 당시 프롬프트. `public/videos/landscape/`와 같아도 백업 목적이 있으므로 삭제하지 않습니다.
- `.video-generation/`, `.audio-generation/`의 작업 ID·원음·요청 상태. Git에서 제외되지만 무조건 지우면 중복 유료 요청과 복구 불가가 생길 수 있습니다.
- `tests/review-regressions.html/.tsx`: 앱 메뉴에는 없지만 브라우저·React·캔버스 회귀 확인에 쓰는 수동 도구입니다.
- 기존 앱 데이터와 부모 설정의 호환 필드. 파일 정리 때문에 사용자의 브라우저 기록을 지우지 않습니다.
- 동물 녹음 라이선스 HTML과 원본 아이콘·이미지 제작 입력. 출처·복구 자료는 사용되지 않는 배포 화면으로 분류하지 않습니다.

`node_modules/`와 `dist/`는 재생성 가능하고 Git에서 제외됩니다. 이번 정리에서는 로컬 의존성 설치를 삭제하지 않았습니다. 의존성 변경 후 새 환경에서는 `npm install`로 설치합니다.

## 변경 후 필수 확인

```sh
npm run lint
npm test
npm run build
```

`lint`는 타입 검사이며 자동 테스트는 서버/API 입력·한도, 저장 음성·언어, 중복 재생·영상 복구, 드롭 수용, 스캐폴딩, 자동 진행·보상, 시간·저장·이동을 포함합니다. 테스트는 공급자 응답을 가짜 데이터로 검증하며 실제 유료 생성 요청을 보내지 않습니다.

수동 회귀 도구는 개발 서버에서 `/tests/review-regressions.html`을 열고 ‘검증 실행’을 누릅니다. 이 도구는 앱의 저장 프로필·유료 API를 사용하지 않습니다. 변경이 관련된 경우 그림 PNG 잘림·지우개·라운드 정리 등을 확인합니다.

UI 변경에는 모바일 390×844·320×568, 태블릿 768×1024·1024×768, PC 1440×900, 짧은 가로 화면을 확인합니다. 게임 진입·오답·정답/완료·자동 다음 문제·홈 복귀, 네 선택지 2×2, 드래그·버튼 겹침, 전체 소리/음성 언어·영상 종료, 부모 정지·복귀와 저장을 실제 조작합니다. 이번 문서·미사용 파일 정리에서는 이전 전체 UI 검증을 새로 했다고 주장하지 않습니다.

## 남아 있는 제한

- 서비스 워커는 제한적인 오프라인 지원이며 모든 지연 로딩 게임·MP4를 보장하지 않습니다.
- 새로운 AI 음성 캐시는 브라우저별입니다. 다른 기기나 캐시 삭제 후 같은 신규 대사를 다시 생성할 수 있습니다. 포함 크레딧·공유 한도를 확인합니다.
- 세로 영상 3명은 완료, 나머지 5명은 미완료입니다. 젤리의 일부 원본 장면과 준비된 더빙은 재개에 재사용합니다. 현재 공급자 잔액·한도는 저장된 과거 기록만으로 알 수 없습니다.
- 환영 화면의 진행률은 5.2초 연출 타임라인입니다. 실제 준비 상태와 연결된 로더는 아닙니다.
- 부모 화면의 스티커 잠금 해제와 기존 앱 상태의 스티커 필드는 이전 시스템 호환 흔적입니다. 현재 색칠 스티커는 그 잠금과 연동하지 않습니다.
- 실제 기기의 소리·진동·멀티터치·PWA 설치는 브라우저 화면 크기 확인과 별개입니다.
- 현재 lockfile이 없어 새 설치의 정확한 전이 의존성 버전은 고정되지 않습니다.

## 문서 갱신과 Git

기능을 바꾸면 README 요약, 해당 상세 문서, 자산 등록과 제작 문서를 함께 갱신합니다. 테스트·청구·화면 기록에는 날짜와 범위를 남기고 원래 결과를 보존합니다. 공급자 가격·한도는 계정별로 달라질 수 있으므로 제작 계획의 가정을 실제 청구 금액처럼 쓰지 않습니다.

[AGENTS.md](../AGENTS.md)의 순서에 따라 status·diff·untracked와 완성된 변경을 검토하고, 의도한 파일만 stage합니다. staged diff를 다시 확인한 후 commit하고 현재 upstream으로 force 없이 push합니다. 키·로컬 환경·생성 작업 디렉터리는 포함하지 않습니다.
