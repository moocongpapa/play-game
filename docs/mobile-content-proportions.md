# 모바일 놀이 콘텐츠 비율 조정

## 변경

- 화면을 채우는 배경과 카드 크기를 분리했다. 세로 카드에 남은 높이를 강제로 배분하지 않는다.
- 그림 선택·규칙·모양·그림자·크기 카드의 높이를 제한하고, 짝맞추기 카드와 슬롯은 정사각형 비율로 배치한다.
- 숫자 접시·글자 방울·리듬 판의 불필요한 빈 영역을 줄인다. 음식 그림은 버튼 안에서 더 분명하게 보이도록 한다.
- 표정 거울·곰 가족의 방·날개 퍼즐·모험의 정적인 장면은 콘텐츠에 맞는 높이로 배치한다.
- 작은 휴대폰에서는 모양·그림자 목표를 캐릭터 안내 옆에 놓아 네 선택지와 아래 버튼이 겹치지 않게 한다.
- 적용 범위는 1024px 이하 세로 화면이다. 배경은 화면을 계속 채우고, 그리기·길 따라가기·풍선·비눗방울 등의 자유 놀이 영역과 이미지 원본 품질은 유지한다.

## 검증

- 390×844 및 320×568에서 유하의 메뉴에 표시되는 29개 게임 첫 화면 검사.
- 320×568에서 카드의 화면 밖 잘림뿐 아니라 아래 버튼과의 겹침도 검사.
- 768×1024에서 조정된 주요 게임 9개의 배치 검사.
- 짝맞추기·모양 맞추기의 실제 드래그와 자동 다음 문제, 무지개 모험의 네 단계 전체 진행·자동 반복 확인.
- lint·build 통과. 브라우저 화면 크기 기반 검증이며 실제 기기 검증은 별도로 필요하다.
