# 전체 놀이 반응형 검증 — 2026-10-09

기록일: 2026-10-09 · [문서 목차](README.md)

숫자 놀이터 추가 전의 전체 플레이 검증 기록입니다. 아래 112개 테스트는 당시 결과이며 현재 전체 테스트 수와 다릅니다. 현재 기능은 [게임 목록](games.md), 최신 검증 절차는 [유지보수](maintenance.md)를 확인합니다.

## 검증 환경

- Codex 내장 브라우저: 모바일 390×844, 태블릿 768×1024, PC 1440×900.
- 추가 화면 배치 검사: 작은 휴대폰 320×568, 태블릿 가로 1024×768.
- 별도 개발 주소 `127.0.0.1:3001`을 사용해 실제 이용 주소의 저장 기록·설정을 분리했다.
- 홈에서 각 게임을 열고 실제 버튼·드래그·키보드 조작으로 진행했다. DOM은 보이는 그림, 접근성 이름, 화면 좌표를 읽는 용도로만 사용했다.
- 일반 문제는 정답 후 새 문제가 자동으로 나오는지, 이야기 놀이는 마지막 장면 후 처음부터 반복되는지 확인했다. 자유 놀이는 각각의 조작과 홈 복귀를 확인했다.

## 수정한 문제

1. **모바일 규칙 놀이의 아래 카드 잘림**: 패턴 참고판과 선택지에 동시에 남은 높이를 배분해 네 선택지가 화면 밖으로 밀렸다. 참고판 높이를 제한하고 2·4개는 두 열, 3개는 세 열로 배치했다. 선택 카드가 남은 공간을 채우도록 했다.
2. **숫자 놀이의 작은 음식 버튼**: 모바일에서 56×56px이던 버튼을 64×64px로 키웠다.
3. **곤충·수족관의 작은 조작 버튼**: 멈춤·다시 모으기 버튼을 58×58px에서 64×64px로 키웠다.

수정 후 모바일의 세 개·네 개 선택지, 작은 휴대폰, 태블릿에서 카드 잘림·스크롤 넘침·작은 조작 영역을 다시 확인했다. 규칙 놀이의 실제 정답 드래그와 자동 새 문제도 세 기본 화면 크기에서 다시 통과했다. 이미지·영상 파일의 해상도나 압축은 변경하지 않았다.

² 연속 놀이의 태블릿 전체 진행은 1024×768 가로 화면에서 확인했다. 양치는 단독 게임의 키보드 경로 외에 태블릿·PC 연속 놀이에서 실제 문지르기 드래그로 끝까지 확인했다.

## 영상·오디오와 검증 범위

- PC의 젤리 가로 영상은 1280×720, 모바일의 핑구 세로 영상은 2160×3840으로 실제 재생·닫기를 확인했다. 세로 제작이 아직 없는 젤리는 기존 가로 원본을 사용한다.
- 놀이 UI 검증은 주로 음소거로 진행했다. 동물 소리의 그림 대체 안내도 확인했다. 실제 기기의 스피커 음질·진동·멀티터치는 이 검증에 포함되지 않는다.
- 기존 자동 테스트 112개 통과: 음성 중복 재생 방지, 영상 종료 후 오디오 복구, 음소거·언어 선택, 저장 음성, 타이머·보상·화면 이탈 정리 등을 포함한다.
- `npm run lint`와 `npm run build` 통과.
- 브라우저의 화면 크기 변경 검증이며 실제 iPhone/iPad/Safari 하드웨어 검증은 별도로 필요하다.
