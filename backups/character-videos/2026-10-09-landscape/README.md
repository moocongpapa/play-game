# 기존 캐릭터 영상 원본 백업

2026-10-09에 `public/videos/`의 영상 8개와 당시 `PROMPTS.md`를 복사했습니다.
영상 원본은 수정·재인코딩하지 않았습니다. 각 MP4의 바이트 수와 SHA-256은
`manifest.json`에 기록되어 있습니다.

이 폴더는 `public/` 밖에 있어 Vite 배포 산출물에 중복 포함되지 않습니다.
새 세로 영상은 아직 생성되지 않았으며 앱의 기존 MP4 파일도 유지되어 있습니다.

복구할 때에는 `manifest.json`의 해시를 검증하고 필요한 MP4를
`public/videos/`의 같은 파일명으로 복사합니다.
